# Chetan & Suhani Wedding Invitation (React + Vite)

A luxury, interactive digital wedding invitation website for **Chetan Kumawat & Suhani Kumawat**, featuring:
- Opening curtain with falling rose petals, Lord Ganesha, and custom gold-foil monogram (`C & S`)
- Live ticking countdown timer to **11 December 2026**
- Full itinerary: Haldi & Mehndi, Sangeet Sandhya at **Laxmi Paradise**, and Shubh Vivah at **Narayana Paradise**
- Interactive Google Maps navigation

---

## 🚀 How to Run

In your terminal / PowerShell inside this directory:

```bash
npm run dev
```

Then visit **`http://localhost:5173`** in your browser.
